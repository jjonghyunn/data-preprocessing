25_DATE_origin 정제 함수 모음 (LET-free, FIND 사용)
2026-04-27  Jonghyun Park w/ Claude
================================================================

[전제]
- LET 함수 사용 안 함 → 모든 Excel 버전에서 동작
- 같은 워크북에 '태깅기획site_code' 시트 존재 (P 함수가 참조)
- R/S 함수 연도는 2025로 박힘 (다른 연도면 함수 안 2025를 변경)

[적용 위치]
- O4, P4, R4, S4, T4 부터 데이터 끝 행까지
- helper 4개 (U/V/W/X) 같은 행에 함께 적용

[Helper 컬럼 역할]
- U: D열의 첫 줄만 추출 (멀티라인 처리)
- V: 분석 대상 (괄호 안에 "/" 있으면 괄호 안, 아니면 U 그대로)
- W: start_part (V에서 ~/- 앞부분)
- X: end_part_clean (V에서 ~/- 뒤 부분 중 첫 공백·괄호 전까지)

> U/V/W/X는 중간 계산용. 보기 싫으면 컬럼 우클릭 → 숨기기.

[중요 — SEARCH 대신 FIND 사용 이유]
SEARCH 함수는 "~"를 와일드카드 escape 문자로 해석.
SEARCH("~", "4/14~5/11") = 1 (잘못된 결과) → 모든 후속 계산 망가짐.
FIND는 와일드카드 미사용 → "~" 그대로 검색됨. 그래서 모든 SEARCH를 FIND로 교체.

================================================================
O4 (Sub 정제값)
================================================================
=IF(IF(OR(NOT(ISBLANK(B4)),ISBLANK(C4),C4="Total"),"",IF(ISNUMBER(FIND("-",C4)),LEFT(C4,FIND("-",C4)-1),IF(ISNUMBER(FIND(" ",C4)),LEFT(C4,FIND(" ",C4)-1),C4)))="한총","sec",IF(OR(NOT(ISBLANK(B4)),ISBLANK(C4),C4="Total"),"",IF(ISNUMBER(FIND("-",C4)),LEFT(C4,FIND("-",C4)-1),IF(ISNUMBER(FIND(" ",C4)),LEFT(C4,FIND(" ",C4)-1),C4))))


================================================================
P4 (태깅기획site_code 매핑)
================================================================
※ 외부 참조 [1]태깅기획site_code 형태로 박혀있으면 P 셀에 다시 한 번 붙여넣어야 외부 참조가 풀립니다.

=IF(ISBLANK('태깅기획site_code'!F4),"",IF(COUNTIF($C$4:$C$100,'태깅기획site_code'!D4&"-"&UPPER(IF(ISNUMBER(FIND("_",'태깅기획site_code'!F4)),LEFT('태깅기획site_code'!F4,FIND("_",'태깅기획site_code'!F4)-1),'태깅기획site_code'!F4)))>0,'태깅기획site_code'!D4&"-"&UPPER(IF(ISNUMBER(FIND("_",'태깅기획site_code'!F4)),LEFT('태깅기획site_code'!F4,FIND("_",'태깅기획site_code'!F4)-1),'태깅기획site_code'!F4)),IF(COUNTIF($C$4:$C$100,'태깅기획site_code'!D4&" ("&PROPER(LEFT('태깅기획site_code'!F4,FIND("_",'태깅기획site_code'!F4)-1))&"_"&UPPER(MID('태깅기획site_code'!F4,FIND("_",'태깅기획site_code'!F4)+1,20))&")")>0,'태깅기획site_code'!D4&" ("&PROPER(LEFT('태깅기획site_code'!F4,FIND("_",'태깅기획site_code'!F4)-1))&"_"&UPPER(MID('태깅기획site_code'!F4,FIND("_",'태깅기획site_code'!F4)+1,20))&")",IF(COUNTIF($C$4:$C$100,'태깅기획site_code'!D4)>0,'태깅기획site_code'!D4,IF(ISNUMBER(FIND("_",'태깅기획site_code'!F4)),"",IFERROR(INDEX($C$4:$C$100,MATCH('태깅기획site_code'!D4,$O$4:$O$100,0)),IF(ISNUMBER(FIND("-",'태깅기획site_code'!D4)),IFERROR(INDEX($C$4:$C$100,MATCH(LEFT('태깅기획site_code'!D4,FIND("-",'태깅기획site_code'!D4)-1),$C$4:$C$100,0)),""),IF('태깅기획site_code'!D4="SCA",IF(RIGHT('태깅기획site_code'!F4,3)="_fr",IFERROR(INDEX($C$4:$C$100,MATCH("SUB_AFRICA (Country_FR)",$C$4:$C$100,0)),""),IF(RIGHT('태깅기획site_code'!F4,3)="_en",IFERROR(INDEX($C$4:$C$100,MATCH("SUB_AFRICA (Country_EN)",$C$4:$C$100,0)),""),"")),""))))))))


================================================================
U4 (Helper: 첫 줄 추출, 멀티라인 처리)
================================================================
=IFERROR(LEFT(D4,FIND(CHAR(10),D4)-1),D4)


================================================================
V4 (Helper: 분석 대상 — 괄호 안에 "/" 있으면 괄호 안, 아니면 U4)
================================================================
=IF(IFERROR(ISNUMBER(FIND("/",MID(U4,FIND("(",U4)+1,FIND(")",U4)-FIND("(",U4)-1))),FALSE),MID(U4,FIND("(",U4)+1,FIND(")",U4)-FIND("(",U4)-1),U4)


================================================================
W4 (Helper: start_part — V에서 ~/- 앞)
================================================================
=IFERROR(TRIM(LEFT(V4,IFERROR(FIND("~",V4),FIND("-",V4))-1)),"")


================================================================
X4 (Helper: end_part_clean — V에서 ~/- 뒤 공백·괄호 전까지)
================================================================
=IFERROR(TRIM(LEFT(TRIM(MID(V4,IFERROR(FIND("~",V4),FIND("-",V4))+1,100)),MIN(IFERROR(FIND(" ",TRIM(MID(V4,IFERROR(FIND("~",V4),FIND("-",V4))+1,100))),99),IFERROR(FIND("(",TRIM(MID(V4,IFERROR(FIND("~",V4),FIND("-",V4))+1,100))),99),LEN(TRIM(MID(V4,IFERROR(FIND("~",V4),FIND("-",V4))+1,100)))+1)-1)),"")


================================================================
R4 (Start_Date) — W4(start_part) 사용
================================================================
=IFERROR(DATE(2025,VALUE(LEFT(W4,FIND("/",W4)-1)),VALUE(MID(W4,FIND("/",W4)+1,10))),"")


================================================================
S4 (End_Date) — X4(end_part_clean) 사용, R 비면 S도 빔
================================================================
=IF(R4="","",IFERROR(DATE(2025,VALUE(LEFT(X4,FIND("/",X4)-1)),VALUE(MID(X4,FIND("/",X4)+1,10))),""))


================================================================
T4 (월/일~월/일 외 텍스트)
================================================================
처리:
- R4 빈 값(파싱 실패) → D열 원본 그대로 (W19~W21, N/A, TBC, MX:3/2 ~ 4/6 등)
- R/S에 괄호 안 날짜가 사용됨(V4≠U4) → 첫 줄의 괄호 외 부분 (예: W18~19)
- R/S에 첫 줄 자체 날짜가 사용됨(V4=U4) → 첫 줄의 괄호 텍스트 (예: (Other Note))
- 멀티라인이면 첫 줄 외 추가 줄도 함께 T로

=IF(R4="",D4,TRIM(IF(V4=U4,IFERROR("("&MID(U4,FIND("(",U4)+1,FIND(")",U4)-FIND("(",U4)-1)&")",""),IFERROR(TRIM(LEFT(U4,FIND("(",U4)-1)),""))&IFERROR(CHAR(10)&MID(D4,FIND(CHAR(10),D4)+1,9999),"")))


================================================================
적용 가이드
================================================================
1. 25_DATE_origin.xlsx 열기 (또는 동일 구조의 일정 파일)
2. '태깅기획site_code' 시트가 같은 워크북에 있는지 확인
3. 셀별 함수 붙여넣기 (한 번씩만, 두 번 붙으면 = 두 개로 깨짐):
   - O4 → O 함수
   - P4 → P 함수 (외부 참조 [1] 박혀있던 거면 새로 입력해야 풀림)
   - U4 → U 함수
   - V4 → V 함수
   - W4 → W 함수
   - X4 → X 함수
   - R4 → R 함수
   - S4 → S 함수
   - T4 → T 함수
4. 각 셀을 데이터 마지막 행까지 드래그/채우기 핸들로 복사
5. R/S 셀 표시 형식을 "날짜"로 지정
6. (선택) U/V/W/X 컬럼 숨기기 — 우클릭 → 숨기기

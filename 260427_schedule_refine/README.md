# 260427_schedule_refine — 캠페인 일정 파일 정제 함수
<!-- 2026-04-27  Jonghyun Park w/ Claude -->

캠페인 일정 원본 xlsx (`*_DATE_origin*.xlsx`)에서 **시트2(태깅기획)의 site별로 매핑되는 Sub의 일정**을 시트1의 R/S/T 컬럼에 Start_Date / End_Date / Note 형태로 정제.

매번 일정 파일이 새로 받아져도 같은 함수를 셀에 붙여넣으면 작동하도록 LET 함수를 쓰지 않는 일반 Excel 함수만 사용.

---

## 폴더 구성

| 파일 | 용도 |
|---|---|
| `25_DATE_origin_sample.xlsx` | sanitize된 샘플 일정 파일. 함수 다 박혀 있어 그대로 열면 R/S/T 결과 확인 가능 |
| `25_DATE_정제함수.txt` | 셀에 붙여넣기 위한 함수 모음 |
| `README.md` | 이 문서 |

---

## 핵심 흐름

```
시트2 (태깅기획) site별 SUBSIDIARY/Site Code
    ↓ P 함수 매핑 (시트2 행 → 시트1 같은 행 P열에 매핑된 Sub명)
시트1 P 컬럼: 매핑된 Sub명 (예: 'SGE')
    ↓
같은 행 R/S/T: P 매핑된 Sub의 일정을 시트1에서 lookup
              (INDEX/MATCH로 같은 시트 C 컬럼에서 P값 찾아 그 행의 Y/Z/AA)
```

예) 시트2에 SGE/ae, SGE/ae_ar 두 행 존재 → 시트1 P4=SGE, P5=SGE  
→ 시트1 R4, R5 모두 시트1 C 컬럼에서 'SGE' 행 찾아 그 행의 Y/Z/AA 가져옴  
→ R/S = SGE의 실제 일정 (예: 3/20~3/23)

## 컬럼 구조

| 컬럼 | 역할 | 비고 |
|---|---|---|
| B | RHQ (지역 본부) | 채워진 행은 region 행, O열 빈 값 처리 트리거 |
| C | Sub (법인 코드) | O 정제 입력, R/S/T lookup 키 |
| D | 1차 캠페인 일정 (`'25 CAMPAIGN NAME`) | Y/Z/AA 파싱 입력 |
| E | 2차 캠페인 일정 (`25 CAMPAIGN NAME 2`) | 참고용, 본 함수 미사용 |
| F | Launching Status | 사용자 수기 입력 |
| G | URL | 사용자 수기 입력 |
| O | Sub 정제값 | 함수 결과 |
| P | 태깅기획 매핑 결과 | 함수 결과 — 시트2 site에 대응되는 Sub명 |
| **R** | **Start_Date** | **함수 결과 — P 매핑된 Sub의 Y 값 lookup** |
| **S** | **End_Date** | **함수 결과 — P 매핑된 Sub의 Z 값 lookup** |
| **T** | **Note** | **함수 결과 — P 매핑된 Sub의 AA 값 lookup** |
| U | (helper) D 첫 줄 | 멀티라인 처리 |
| V | (helper) 분석 대상 | 괄호 안 날짜 우선 |
| W | (helper) start_part | ~/- 앞 |
| X | (helper) end_part_clean | ~/- 뒤 공백·괄호 전까지 |
| Y | (helper) 같은 행 Start_Date | 같은 행 D를 파싱한 결과 |
| Z | (helper) 같은 행 End_Date | 같은 행 D를 파싱한 결과 |
| AA | (helper) 같은 행 Note | 같은 행 D의 비-날짜 텍스트 |

## D열 → Y/Z/AA 파싱 케이스

| D열 입력 | Y (Start) | Z (End) | AA (Note) |
|---|---|---|---|
| `4/14~5/11` | 2025-04-14 | 2025-05-11 | (빈) |
| `4/28 ~ 5/12` | 2025-04-28 | 2025-05-12 | (빈) |
| `5/12 - 5/26` | 2025-05-12 | 2025-05-26 | (빈) |
| `5/2~6/30 (Other Note)` | 2025-05-02 | 2025-06-30 | `(Other Note)` |
| `W18~19 (4/28~5/11)` | 2025-04-28 | 2025-05-11 | `W18~19` |
| `3/19 ~4/1 (Note 1)` | 2025-03-19 | 2025-04-01 | `(Note 1)` |
| `W19~W21` | (빈) | (빈) | `W19~W21` |
| `N/A` | (빈) | (빈) | `N/A` |
| `TBC` | (빈) | (빈) | `TBC` |
| 멀티라인 `3/17~3/24\nMX:3/2~4/6` | 2025-03-17 | 2025-03-24 | `MX:3/2~4/6` |

## 적용 가이드

1. 일정 원본 xlsx 열기 (`*_DATE_origin*.xlsx`)
2. 같은 워크북에 `태깅기획site_code` 시트가 있는지 확인 (P 함수가 참조)
3. `25_DATE_정제함수.txt` 의 각 함수를 해당 셀(O4, P4, U4~X4, Y4~AA4, R4~T4)에 **한 번씩만** 붙여넣기
   - 두 번 붙으면 `=` 두 개로 깨짐 (수식 바에 `=...=...` 형태로 보임)
4. 채우기 핸들로 데이터 마지막 행까지 복사
5. R/S/Y/Z 셀 표시 형식을 "날짜"로 지정
6. (선택) U/V/W/X/Y/Z/AA 컬럼 숨기기

## 트러블슈팅

| 증상 | 원인 / 해결 |
|---|---|
| R/S 비어있음 | (a) P 매핑이 빈 값 → 시트2 행에 매칭되는 Sub가 시트1 C에 없음. (b) 함수 셀이 `=` 두 개로 깨졌는지 수식 바 확인 |
| W가 다 빈 값, X가 한 글자 잘려서 `/14~5/11` 형태 | `SEARCH("~", ...)` 가 `~`를 와일드카드 escape로 해석한 것. 본 함수는 `FIND` 사용으로 회피 |
| P 셀이 `[1]태깅기획site_code!F4` 외부 참조로 나옴 | P 셀에 함수를 새로 한 번 붙여넣어야 외부 참조가 풀림 |
| LET 함수 미지원 (#NAME?) | 본 함수는 LET 안 씀 — 모든 Excel 버전에서 동작 |
| 자동 재계산 안 됨 | 수식 → 계산 옵션 → 자동, 또는 Ctrl+Alt+F9 |

## 연도 변경

Y/Z 함수에 `DATE(2025, ...)` 로 박혀있음. 다른 연도 일정이면 Y/Z 안 `2025` 를 원하는 연도로 변경하고 채우기 핸들로 다시 복사.

## 샘플 데이터 안내

`25_DATE_origin_sample.xlsx` 의 데이터는 모두 익명/임의 키워드로 작성된 샘플:
- 법인명: `SUB1`, `SUB2`, ... `SUB20`
- Region: `RegA~RegD` / `Reg1~Reg5`
- Country: `Country_A~Country_U`
- Site Code: `s1_main`, `s_africa_en`, `s13_a` 등
- 캠페인명: `CAMPAIGN NAME` / `CAMPAIGN NAME 2`
- URL: `example.com`

함수 검증과 케이스 학습용. 실제 일정 파일에 함수를 적용하려면 위 가이드 따라 셀에 붙여넣으면 됨.

샘플에서 `SUB13` (R20)이 시트2 R4, R5에 두 번 매핑된 SUB13에 해당 — 두 행 모두 R/S = `2025-03-20` / `2025-03-23` (SUB13의 D20 일정 `3/20~3/23`)으로 같이 나오는 게 정상.

# 260427_schedule_refine — 캠페인 일정 파일 정제 함수
<!-- 2026-04-27  Jonghyun Park w/ Claude -->

캠페인 일정 원본 xlsx (`*_DATE_origin*.xlsx`) 의 D열 일정 텍스트(`월/일~월/일` 등)를 R/S/T 컬럼의 Start_Date / End_Date / Note 로 정제하기 위한 Excel 함수 모음.

매번 일정 파일이 새로 받아져도 같은 함수를 셀에 붙여넣으면 작동하도록 LET 함수를 쓰지 않는 일반 Excel 함수만 사용.

---

## 폴더 구성

| 파일 | 용도 |
|---|---|
| `25_DATE_origin_sample.xlsx` | sanitize된 샘플 일정 파일 (시트1 일정파일, 시트2 태깅기획site_code). 함수 다 박혀 있어 그대로 열면 R/S/T 결과 확인 가능 |
| `25_DATE_정제함수.txt` | 셀에 붙여넣기 위한 함수 모음 (O, P, R, S, T, U, V, W, X) |
| `README.md` | 이 문서 |

---

## 컬럼 구조

| 컬럼 | 역할 | 비고 |
|---|---|---|
| B | RHQ (지역 본부) | 채워진 행은 region 행, O열 빈 값 처리 트리거 |
| C | Sub (법인 코드) | O 정제 입력 |
| D | 1차 캠페인 일정 (`'25 CAMPAIGN NAME`) | R/S/T 정제 입력 |
| E | 2차 캠페인 일정 (`25 CAMPAIGN NAME 2`) | 참고용, 본 함수 미사용 |
| F | Launching Status | 사용자 수기 입력 |
| G | URL | 사용자 수기 입력 |
| O | Sub 정제값 | 함수 결과 |
| P | 태깅기획 매핑 결과 | 함수 결과 |
| R | Start_Date | 함수 결과 (W 사용) |
| S | End_Date | 함수 결과 (X 사용) |
| T | Note (날짜 외 텍스트) | 함수 결과 |
| U | (helper) D 첫 줄 | 멀티라인 처리 |
| V | (helper) 분석 대상 | 괄호 안 날짜 우선 |
| W | (helper) start_part | ~/- 앞 |
| X | (helper) end_part_clean | ~/- 뒤 공백·괄호 전까지 |

---

## 함수 흐름

```
D열 원본
  ↓
U: 첫 줄만 (멀티라인이면 CHAR(10) 이전)
  ↓
V: 괄호 안에 "/" 있으면 괄호 안, 아니면 U 그대로 (예: "W18~19 (4/28~5/11)" → "4/28~5/11")
  ↓
W: V에서 ~/- 앞부분 (start_part)
X: V에서 ~/- 뒤 공백·괄호 전까지 (end_part_clean)
  ↓
R: DATE(2025, W의 월, W의 일)
S: DATE(2025, X의 월, X의 일)  ※ R이 비면 S도 비움
T: R이 비면 D 원본, 아니면 (괄호 텍스트 또는 W18~19 같은 prefix) + 멀티라인 추가 줄
```

## 케이스별 R/S/T 결과

| D열 입력 | R (Start) | S (End) | T |
|---|---|---|---|
| `4/14~5/11` | 2025-04-14 | 2025-05-11 | (빈) |
| `4/28 ~ 5/12` | 2025-04-28 | 2025-05-12 | (빈) |
| `5/12 - 5/26` | 2025-05-12 | 2025-05-26 | (빈) |
| `5/2~6/30 (Other Note)` | 2025-05-02 | 2025-06-30 | `(Other Note)` |
| `W18~19 (4/28~5/11)` | 2025-04-28 | 2025-05-11 | `W18~19` |
| `3/19 ~4/1 (Note 1)` | 2025-03-19 | 2025-04-01 | `(Note 1)` |
| `W19~W21` | (빈) | (빈) | `W19~W21` |
| `N/A` | (빈) | (빈) | `N/A` |
| `TBC` | (빈) | (빈) | `TBC` |
| `3/17~3/24\nMX:3/2~4/6\nDA/VD:2/3~3/31` | 2025-03-17 | 2025-03-24 | `MX:3/2~4/6\nDA/VD:2/3~3/31` |
| `MX:3/2 ~ 4/6\nVD:2/17~3/31` | (빈) | (빈) | `MX:3/2 ~ 4/6\nVD:2/17~3/31` |

## 적용 가이드

1. 일정 원본 xlsx 열기 (`*_DATE_origin*.xlsx`)
2. 같은 워크북에 `태깅기획site_code` 시트가 있는지 확인 (P 함수가 참조)
3. `25_DATE_정제함수.txt` 의 각 함수를 해당 셀(O4, P4, U4, V4, W4, X4, R4, S4, T4)에 **한 번씩만** 붙여넣기
   - 두 번 붙으면 `=` 두 개로 깨짐 (수식 바에 `=...=...` 형태로 보임)
4. 채우기 핸들로 데이터 마지막 행까지 복사
5. R/S 셀 표시 형식을 "날짜"로 지정
6. (선택) U/V/W/X 컬럼 숨기기

## 트러블슈팅

| 증상 | 원인 / 해결 |
|---|---|
| R/S 비어있음 | (a) 자동 계산이 꺼짐 → 수식 탭 → 계산 옵션 → 자동. (b) 셀 함수가 `=` 두 개로 깨졌는지 수식 바 확인 |
| W가 다 빈 값, X가 한 글자 잘려서 `/14~5/11` 형태 | `SEARCH("~", ...)` 가 `~`를 와일드카드 escape로 해석한 것. 본 함수는 `FIND` 사용으로 회피 — txt의 함수 그대로 붙여 넣으면 됨 |
| P 셀이 `[1]태깅기획site_code!F4` 외부 참조로 나옴 | P 셀에 함수를 새로 한 번 붙여넣어야 외부 참조가 풀림 |
| LET 함수 미지원 (#NAME?) | 본 함수는 LET 안 씀 — 모든 Excel 버전에서 동작 |

---

## 연도 변경

R/S 함수에 `DATE(2025, ...)` 로 박혀있음. 다른 연도 일정이면 함수 안 `2025` 를 원하는 연도로 변경하고 채우기 핸들로 다시 복사.

## 샘플 데이터 안내

`25_DATE_origin_sample.xlsx` 의 데이터는 모두 익명/임의 키워드로 작성된 샘플:
- 법인명: `SUB1`, `SUB2`, ... (실제 법인 코드와 무관)
- Region: `RegA`, `RegB`, ... (실제 RHQ와 무관)
- Country: `Country_A`, `Country_B`, ... (실제 국가와 무관)
- Site Code: `s1_main`, `s_africa_en`, ... (실제 사이트 코드와 무관)
- 캠페인명: `CAMPAIGN NAME` / `CAMPAIGN NAME 2`
- URL: `example.com`

함수 검증과 케이스 학습용. 실제 일정 파일에 함수를 적용하려면 위 가이드 따라 셀에 붙여넣으면 됨.
